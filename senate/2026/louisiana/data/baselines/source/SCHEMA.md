# Louisiana partisanship source and calculator schema

Version 1, researched October 20, 2026. `county-` filenames contain Louisiana **parishes**, not municipalities or conventional counties. No FIPS or geographic equivalence is inferred from alphabetical source codes.

## Immutable originals and replay

`receipts.json` pins individual shared originals by exact relative repository path, raw/stored SHA256, byte size, requested/final URL, original UTC retrieval, status and complete available final headers. The shared bodies are read-only references, not a reconstruction dependency on their mutable discovery ledger, directory listing, preparation helpers or newsroom derivatives. `../original-freeze.json` retains the original-first extraction manifest and full original receipts. `*.receipt.json` in this directory describes each independently acquired complete anonymous public response with the same fields. Original raw entities are gzip-compressed losslessly with `mtime=0`; decompress once, verify raw hash/bytes. No truncation, cell suppression, source repair or residual allocation occurs. Retained failed requests include three incomplete native constructors returning 404 before the full published race+parish constructor was used. Sandbox DNS failure is separate from HTTP failure.

Receipts preserve the final response entity and headers; unretained intermediate redirect entities, transport framing and TLS exchanges are unknown. Published WriteTime, VersionDateTime, election/status flags and retrieval clocks are separate. `1900-01-01T00:00:00` is retained literally, not interpreted as a publication time. Historical metadata's January 10, 2026 WriteTime is republication evidence, not election-night sequencing or certification date. ElectionDates `ResultsOfficial=1` marks these three historical results official; no independently signed certification date is supplied.

Public authority chain: SOS results index -> explicitly linked `sosscript.js` production substitution -> `/graphical` -> GraphicalConfig / complete public bundle -> ElectionDates / metadata / XLSX and CSV constructors. No media authentication, account, credential, personal form or current vote request is used. Complete originals include unrelated offices and background JSON fields; those remain in their original bytes/position witness without a second analytical table for unrelated contests.

`../extract.py` uses only standard-library ZIP/XML/CSV/JSON. Workbook relationships resolve actual member paths (including 2020 `xl/worksheets/sheet.xml`). XML physical row and cell ordinals are 1-based regardless of missing explicit `r` addresses. Empty cells retain `value:null`, attributes and XML; empty rows remain. `workbook-position-witness.json.gz` is every physical row/cell in every sheet, including unrelated offices, overlapping local sheets, nulls and context. No whole-workbook sheet total is added to parish/native totals.

`json-position-witness.json.gz` retains every node of the original-first JSON entities as `[source_id, JSON_pointer, child_ordinal, type, scalar_or_container_length]`. Complete bytes are authoritative for exact punctuation/order. Duplicate source object fields are independently checked in source QA; none may be silently used as candidate keys. CSV position witnesses retain literal ordered headers, all complete field arrays and physical record ordinals (header=1). `../native-position-links.json.gz` joins selected native vectors to exact workbook physical rows/cells, original CSV ordinals and API JSON pointers. Source headers `(OTHER)` and `(OTH)` are retained separately; only explicit comparison adapters treat their formatting alias as equal. The source's 2024 Stein/Ajamu Baraka label is literal export evidence, not a repaired or independently established legal running-mate identity.

## Baselines, identities, controls and coverage

Required contests: 2024-11-05 Presidential Electors, race 67190, 11 choices; 2022-11-08 U.S. Senator, race 61897, 13 choices, other Class III seat/midterm; 2020-11-03 U.S. Senator, race 59569, 15 choices, same Class II seat. Each covers all64 parishes. Historical first-election fields stay distinct; no synthetic runoff/RCV round is invented. Cassidy and Kennedy each actually exceeded half the complete named-candidate total in the first election.

`../candidates.csv`: one row per original candidate column, `source_column` 1-based in parish CSV, literal header, metadata label, choice ID, party literal, statewide count, complete-field denominator/share. Metadata and original raw headers survive; independent, Libertarian, No Party, Green and Other identities stay separate. No non-Republican pool is labeled Democratic.

`../parish-controls.csv`: 192 parish/contest rows, source parish code, complete ordered candidate vector serialized as JSON, named-candidate sum, selected-race qualified/voted and separate general-statistics qualified/voted, reported/expected ordinary/absentee control counts. Null blank/under/over fields mean absent, never zero. `../scope-controls.json` preserves original election metadata, selected RaceStats high-level/parish arrays, general Stats statewide object, exact differences and explicit unknown contexts. Qualified means source `All`/`VoterCountQualified`; active/inactive roll scope, registration cutoff/date and voting-eligible population remain unspecified. Voted is a source voter statistic, not asserted physical ballots cast. Voted-minus-contest votes cannot establish undervotes, overvotes or blank ballots.

`../native-results.json.gz`: all12,060 selected native source records (3933/4065/4062 in2024/2022/2020) in original CSV/API order, complete candidate vectors, `key=JSON([year,parish_code,ward_literal,precinct_literal])`, raw source ID, CSV/API ordinals, method type, qualified/voted/HasReported fields, and exact-label statistics object when available. Missing native qualified/voted values are null. Ward/precinct strings include zero-padding, letters and punctuation without coercion. The original export's Early Voting and Provisional Votes have blank precinct strings; their workbook display includes the trailing space. Early Voting is a source aggregate of unproved composition, not automatically early-in-person alone. Ordinary-looking zero-vote source rows without voter controls remain present and unclassified beyond their source row kind.

`../native-hierarchy.json.gz` stores every parish parent and complete child/method arrays; parish totals overlap their children. `../native-coverage.json` gives complete source result/statistics row counts, exact-label overlap, sums of known controls and missing counts per parish/year. Precinct statistics cover enrolled precinct voter controls; early/provisional result aggregates lack those separate controls. General Stats and selected RaceStats differ in2022/2020. Preserve both vintages/scopes; no causal correction story is inferred.

`../../county-baselines.csv`: 192 long parish baselines, named A/B labels/counts, complete field headers/vector, separate party totals, pair participation/share/margin and registration/voter/null context. `../native-baselines.json.gz`: every native named pair and other count, source volume, participation, pair/all weights, net contribution and +1 share-point gain. Zero pair volume gives undefined/null preference.

`../full-orders.json.gz`, `../all-source-orders.json.gz` and `../historical-priority-contract.json.gz`: full descending historical source orders, never only a selected subset. Sort votes descending, then literal source key lexicographically (parish name/source code have the same ordering here; native key adapter inserts race ID without changing the order within year). Minimum80 uses exact integer `5*cumulative >= 4*total`, first crossing only; threshold ceiling `(4*total+4)//5`. All27 source order contexts survive separately, including parish method/qualified/voted and selected-race controls. `current_canonical_dispatch:null`, `current_canonical_units:[]`; historical source completeness is not November geometry/current-ID or coordinator approval.

## Historical sensitivity settings

A/B: Harris/Trump2024, Chambers/Kennedy2022, Perkins/Cassidy2020. They are named pairs, not aggregated party nominees/coalitions. Other candidates preserve complete source identities and their within-other proportions. All64 parishes and every native/admin/zero-pair context remain in each applicable whole-state calculation.

Parish low/base/high volume mixes use complete2022Senate/2024president/2020Senate named-candidate totals **per parish**, respectively. Preference and pair-participation anchors independently use each of the three contests. Thus pair volume is `mix_all_candidate_volume * preference_year_pair_participation`, not mix-year pair counts. This is a parish sensitivity, not a cross-year native join or2026 projection. Historical voter electorates differ.

Native scenarios stay within each original year/identity: low=0.8 times every source volume; base=1.0; high=1.2 times every source volume, additionally1.25 times the source Early Voting aggregate. These scale/mix settings are explicitly illustrative stress assumptions around measured historical volumes, not empirically estimated bounds. Preference/participation remain same-year original anchors. No source-unknown preference becomes0.5.

`../state-scenarios.csv` holds36 tie/A+1 results across18 inputs. `../scenarios/` retains each complete supplied input and full outputs. `../all-unit-scenarios.json.gz` retains73,512 unit contributions/weights/gains/clip flags/targets and selected-only thresholds, with every other unit fixed at its named baseline assumptions. `../priority-contributions.json` separately sums priority/outside-priority units for every scenario; the complete universe is always used. `../full-field-constraints.json` reports full candidate-volume constraints separately from pair thresholds; majority/plurality inequalities are strict and assume the supplied complete named field and frozen other allocation, not a legal declaration.

## Offline calculator JSON contract

Run `python3 -B calculator.py input.json` or supply a complete JSON object on stdin with `-`. Top-level required: `mode` (`historical` or `live`), `A`, `B` distinct nonblank candidate strings, `other_candidates` array of distinct nonblank strings, `target` numeric finite fraction[-1,1], `units` array. Optional: `selected_unit` exact existing key or null, `assumption` label. JSON duplicate fields/nonfinite tokens are invalid. Expected input errors emit strict JSON `status:invalid-input`, exit2 and empty stderr. Valid inputs exit0. No NaN/Infinity serialization.

Every supplied unit key must globally be a distinct, nonblank string, even in unknown/no-pool branches or outside selection. Whitespace only tests blankness; literal strings are preserved. Every candidate identity is globally distinct; no A/B/other collision. Validate every unit and all settings before arithmetic/early return.

Historical unit requires `key`, `volume` (complete all-candidate scenario volume), `participation` (pair fraction[0,1]), `share` (A's pair fraction[0,1] or null for unknown), `other_allocation` (complete mapping of other identities to nonnegative finite fractions totaling1). If other pool is exactly zero, all-zero allocation is also accepted as unused, without inventing preferences. With no other candidates participation must equal1. Live unit replaces volume with `remaining` nonnegative finite all-candidate pool and `counted` containing every supplied candidate with fixed finite nonnegative votes. `all_candidate_total` optional control must equal historical volume or live counted total and cannot be smaller than counted pair. Negative/bool/null/text/nonfinite counts/volumes/participation/allocations, unsupported fields/modes and aggregate/derived overflow are rejected.

For live mode, final pair denominator=`counted_A+counted_B + sum(remaining*participation)`; final complete-field denominator=`all_counted_candidates + sum(remaining)`. Preferences affect only the remainder; counted candidate vectors never move. Other allocation applies only to remaining nonpair votes. Unknown positive-pool pair preference stays unknown; no pool and fixed-target status are separate. A pair leader can trail another supplied candidate; arithmetic plurality leaders are reported separately and are not legal calls.

Uniform unbounded shift is `(target_margin*FINAL_pair_votes - baseline_final_net)/(2*remaining_pair_votes)`; historical mode has zero counted. Historical fixed weights reduce tie to `(B-A)/(2*(A+B))`. A+1 pair-margin target=.01 adds.005 A-share (0.5 share points) to the **unbounded** tie shift. One A-share point adds two pair-margin points and `.02*pair_volume` net votes. Bounded shifts clip each known share to[0,1] and solve the common root by bisection; complete contributions and residual remain. Clipping can make the feasible shift differ from unbounded algebra and the bounded tie-to-cushion gap differ from.005. An infeasible target outside attainable endpoints is explicitly impossible/already-secured; absent positive pair pool has undefined shift.

Selected-only threshold is `(target_margin*FINAL_pair_votes - fixed_counted_and_other_remainder_net + selected_pair_pool)/(2*selected_pair_pool)`. Other units keep their explicit baseline assumptions. Unknown positive-pool other-unit preference produces `unknown-other-units`; zero selected pair pool gives `no-positive-pool` plus fixed-target status. Raw negative or>1 requirements are retained as already-secured/impossible, never clipped into a feasible claim. Zero pair denominator leaves preference/margin undefined.

## Verification and retained failures

`../qa.py`:61 actual synthetic CLI fixtures, strict stdout/exit/stderr checks, independent hand controls, independent piecewise clipping inversion across36 whole-state targets and substitution checks of every selected threshold. `../source_cli.py`: two complete actual historical CLI runs. `../reproduce.py`: temporary isolated offline original-only extraction/build replay, exact byte comparisons, never peer parsers or mutable ledgers. `../audit.py`: original/asset hashes, identities/coverage, candidate/method balances, hierarchy/order/80, schema/relative links and strict size/membership checks. `../history/` preserves exact failed checker/source-script/input/output/claim bytes before bounded fixes; adapter/checker defects remain distinguished from source/model defects. `../final-seal.json` summarizes completion; `../asset-manifest.json` is generated last and excludes only itself. Final audit runs read-only after the seal/manifest and is reported in the handoff, avoiding a digest cycle.

Historical source controls and captured peer-source equality only: no future outcome, final ballot, known2026 returns, eligibility, current geometry, live cadence or calculator equality follows. Actual November ballot mapping remains unverified; setup race/choice IDs are not reused as genuine returns.
